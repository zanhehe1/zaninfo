DEPLOY / RENDER

Build Command:
  pip install -r requirements.txt

Start Command:
  python Main.py

Render service type:
  Web Service

Main.py reads Render's PORT environment variable and binds the dashboard to 0.0.0.0.
The dashboard now displays recent bot logs in a live console panel.

IMPORTANT:
- Upload the whole project folder/repository, not only Main.py.
- Do not upload real account passwords, access tokens, token_cache.json, or devices.json to a public repository.
- accounts.json is intentionally empty in this bundle.
- Check game/service terms before using account automation.
